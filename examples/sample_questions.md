# 样例问题（POC 演示用）

> 对应 `data/registry.yaml` 的注册指标 + 行级权限 + 敏感表配置。
> `role` 决定行级权限与敏感表访问权。

| 问题 | 角色 | 预期 |
|---|---|---|
| 一季度华东区域营收 | east | 命中「区域营收」，行级权限过滤到华东/华北 → 结果 200000 |
| 一季度华南区域营收 | east | 华南不在 east 范围 → 空结果（越权范围外） |
| 一季度区域营收 | national | 全区域 2026Q1 → 505000 |
| 一季度订单量 | south | COUNT 指标，south→华南/华中 → 2 |
| 员工薪酬总额 | east | 敏感表 hr_salary，east 非白名单 → 拦截 |
| 研发部薪酬总额 | national | 敏感表白名单放行，dept=研发 → 62000 |
| 今天天气怎么样 | national | 未注册指标 → 拦截 |
